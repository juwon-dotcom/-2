# Python Quiz Game

파이썬으로 만든 콘솔 기반 퀴즈 게임입니다.

## 주요 기능

- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 보기
- 퀴즈 삭제
- 최고 점수 저장
- 퀴즈 데이터 저장 및 불러오기

## 실행 방법

터미널에서 아래 명령어를 실행합니다.

```bash
py main.py
```

또는 환경에 따라 다음 명령어를 사용할 수 있습니다.

```bash
python main.py
```

## 메뉴 구성

```text
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록 보기
4. 퀴즈 삭제
5. 최고 점수 보기
6. 종료
```

## 데이터 저장

퀴즈 데이터와 최고 점수는 `quiz_data.json` 파일에 저장됩니다.

프로그램을 종료했다가 다시 실행해도 추가한 퀴즈와 최고 점수가 유지됩니다.
