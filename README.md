# Python Quiz Game

## 프로젝트 개요

파이썬으로 만든 콘솔 기반 퀴즈 게임입니다.  
사용자는 신체 구조와 관련된 퀴즈를 풀고, 퀴즈를 추가하거나 삭제할 수 있습니다.  
퀴즈 데이터와 최고 점수는 `state.json` 파일에 저장됩니다.

## 퀴즈 주제 선정 이유

신체 구조는 일상생활과 건강 이해에 도움이 되는 기본적인 학습 주제입니다.  
골격계, 순환계, 호흡계, 신경계, 소화계 등 우리 몸의 주요 구조를 퀴즈로 학습할 수 있도록 선정했습니다.

## 실행 방법

터미널에서 프로젝트 폴더로 이동한 뒤 아래 명령어를 실행합니다.

```bash
py main.py
```

환경에 따라 아래 명령어를 사용할 수도 있습니다.

```bash
python main.py
```

## 기능 목록

- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 보기
- 퀴즈 삭제
- 최고 점수 보기
- 퀴즈 데이터 저장 및 불러오기
- 최고 점수 저장

## 데이터 파일 설명

### state.json

`state.json` 파일은 프로젝트 루트에 생성됩니다.  
퀴즈 목록과 최고 점수를 저장하는 JSON 파일입니다.

저장되는 주요 데이터는 다음과 같습니다.

```json
{
  "high_score": 0,
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
      "answer": 1
    }
  ]
}
```

프로그램은 `state.json`을 UTF-8 인코딩으로 저장하고 불러옵니다.
