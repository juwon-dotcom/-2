# Python Quiz Game

## 프로젝트 개요

파이썬으로 만든 콘솔 기반 퀴즈 게임입니다.  
사용자는 운동역학과 관련된 퀴즈를 풀고, 퀴즈를 추가하거나 삭제할 수 있습니다.  
퀴즈 데이터와 최고 점수는 `state.json` 파일에 저장됩니다.

## 퀴즈 주제 선정 이유

운동역학은 인체 움직임과 힘의 작용을 이해하는 데 중요한 학습 주제입니다.  
관절 운동, 근수축, 지레 원리, 무게중심, 운동량 등 주요 개념을 퀴즈로 학습할 수 있도록 선정했습니다.

## 실행 방법

터미널에서 프로젝트 폴더로 이동한 뒤 아래 명령어를 실행합니다.

```bash
py main.py
```

환경에 따라 아래 명령어를 사용할 수도 있습니다.

## 데이터 저장 규칙

### state.json

`state.json` 파일은 프로젝트 루트에 생성됩니다.  
퀴즈 목록과 최고 점수를 저장하는 JSON 파일입니다.

저장되는 주요 데이터는 다음과 같습니다.

```json
{
  "high_score": 0,
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
      "answer": 1
    }
  ]
}
```

프로그램은 `state.json`을 UTF-8 인코딩으로 저장하고 불러옵니다.

### JSON 저장 방식을 사용한 이유

`state.json`은 사람이 직접 읽기 쉽고, 퀴즈 목록과 최고 점수를 구조적으로 저장하기에 적합합니다.

또한 Python의 `json` 모듈을 사용하면 딕셔너리와 리스트 구조를 쉽게 파일로 저장하고 다시 불러올 수 있습니다.

### 데이터 로드/저장 시점

프로그램 시작 시 `QuizGame` 객체가 생성되면서 `load_state()`를 호출하여 `state.json` 데이터를 불러옵니다.

퀴즈를 추가하거나 최고 점수가 갱신될 때는 `save_state()`를 호출하여 현재 상태를 저장합니다.

`Ctrl + C`로 인한 사용자 중단은 `KeyboardInterrupt`로, 시스템 종료 신호인 `SIGTERM`은 `signal.signal()`로 처리하고 종료 전 `save_state()`를 호출하여 데이터를 보존합니다.

## 파일 권한 오류 발생 시 대처 방법

`state.json` 저장 중 권한 오류가 발생할 수 있습니다.

예상 원인:

- 파일이 읽기 전용으로 설정된 경우
- 다른 프로그램에서 파일을 사용 중인 경우
- 저장 폴더에 쓰기 권한이 없는 경우

복구 절차:

1. 프로그램을 종료합니다.
2. `state.json` 파일 속성에서 읽기 전용 여부를 확인합니다.
3. VS Code 또는 다른 편집기에서 해당 파일을 닫습니다.
4. 프로젝트 폴더의 쓰기 권한을 확인합니다.
5. 필요하면 `state_backup.json` 파일을 `state.json`으로 복사하여 복구합니다.

## 대규모 퀴즈 데이터 처리 한계와 개선 방안

현재 프로젝트는 퀴즈 데이터를 리스트에 저장합니다.

```python
self.quizzes = []
```
이 방식은 퀴즈 수가 적을 때는 단순하고 이해하기 쉽습니다.
하지만 퀴즈가 1000개 이상으로 많아질 경우 다음과 같은 한계가 있습니다.

- 전체 데이터를 한 번에 메모리에 불러와야 함
- 특정 문제 검색 시 리스트 전체를 순회해야 할 수 있음
- 화면에 모든 퀴즈를 한 번에 출력하면 가독성이 떨어짐

### 개선 방안:

페이징 처리
- 퀴즈 목록을 10개 또는 20개 단위로 나누어 출력합니다.

인덱싱
- 문제 번호나 카테고리를 기준으로 빠르게 찾을 수 있도록 딕셔너리를 활용합니다.

데이터베이스 사용
- 데이터가 더 커질 경우 SQLite 같은 내장 데이터베이스 사용을 검토할 수 있습니다.

검색 기능 분리
- 문제 검색, 카테고리 검색 기능을 별도 메서드로 분리합니다.

## 코드 구조

### 주요 메서드 책임

| 메서드 | 역할 | 입력 | 출력 |
|---|---|---|---|
| `input_number(message, min_value, max_value)` | 숫자 입력 검증 | 안내 문구, 최소값, 최대값 | 검증된 정수 |
| `solve_quiz()` | 퀴즈 진행 및 점수 계산 | 없음 | 점수 갱신 |
| `load_state()` | 저장 파일 읽기 | `state.json` | 퀴즈 목록, 최고 점수 로드 |
| `save_state()` | 현재 상태 저장 | 퀴즈 목록, 최고 점수 | `state.json` 저장 |
| `add_quiz()` | 새 퀴즈 추가 | 사용자 입력 | 퀴즈 목록에 추가 |

입력 검증, 게임 진행, 파일 입출력을 각각 다른 메서드로 분리의 장점은 유지보수성을 높은 것입니다.  
예를 들어 입력 방식이 바뀌어도 `input_number()`만 수정하면 되고, 저장 방식이 바뀌어도 `save_state()` 중심으로 수정할 수 있습니다.

### 클래스 설계 이유

이 프로젝트는 `Quiz`와 `QuizGame` 클래스를 사용하여 데이터를 표현하는 부분과 게임을 진행하는 부분을 분리했습니다.

클래스를 사용한 이유는 다음과 같습니다.

1. 추상화  
   퀴즈 하나를 `Quiz` 객체로 표현하여 문제와 정답을 하나의 단위로 관리할 수 있습니다.

2. 재사용성  
   `Quiz` 객체는 퀴즈 추가, 저장, 불러오기 기능에서 반복적으로 사용할 수 있습니다.

3. 유지보수성  
   게임 진행 로직은 `QuizGame`에 모아두어 기능 수정 시 영향 범위를 줄일 수 있습니다.

### Quiz 클래스

`Quiz` 클래스는 하나의 퀴즈 데이터를 표현합니다.

주요 책임:

- 문제 내용 저장
- 정답 저장
- 퀴즈 객체를 딕셔너리 형태로 변환
- 저장된 딕셔너리 데이터를 다시 퀴즈 객체로 복원

### QuizGame 클래스

`QuizGame` 클래스는 전체 퀴즈 게임의 흐름을 관리합니다.

주요 책임:

- 퀴즈 목록 관리
- 사용자 입력 처리
- 정오답 판정
- 점수 계산
- 최고 점수 저장
- `state.json` 파일 로드/저장
